# Software QA & Testing Portfolio

A practical QA portfolio project demonstrating structured manual testing, negative testing, boundary value analysis, API testing concepts, integration testing, and clear bug reporting.

## Project scope

This repository documents a sample authentication workflow with:
- User registration
- User login
- Input validation
- API request/response checks
- Frontend-to-backend integration scenarios

> **Important:** This is a QA practice project. Test cases and examples are documented as planned scenarios. Only mark a test as Pass or Fail after you have actually executed it against a defined application or API.

## Testing techniques

- Functional testing
- Positive and negative testing
- Boundary value analysis
- Input validation
- API testing
- Integration testing
- Bug reproduction and documentation

## Tools

- Git and GitHub for version control
- Bash / Git Bash for command-line workflow
- Postman for API testing (when executed)
- Markdown for test documentation

## How to use

1. Choose a demo application or API.
2. Review the test plan and test cases.
3. Execute each test and record the actual result.
4. Create a bug report for every reproducible defect.
5. Update the test summary with real execution results.
